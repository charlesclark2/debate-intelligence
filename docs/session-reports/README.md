# Session reports

One report per task, named `<task-name>.md`, created by `scripts/task start` from
[the template](../process/session-report-template.md), completed by the implementation session,
and reviewed by the PM (the **PM review** section). Each report is merged into `dev` with its
task's PR, so this directory is the permanent record of what was built, how it was verified,
and why it was accepted.
