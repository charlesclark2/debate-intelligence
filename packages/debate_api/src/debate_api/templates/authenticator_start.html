Set up a new authenticator app

Use this when you have a new phone. When you choose Start, your current authenticator app stops working at once, and the new one works only after you scan its QR code and enter a code from it.

So have the new phone ready, with an authenticator app on it, and finish in one sitting: you then have five minutes to enter a code from the new app.

If you are signed out partway through, sign in again straight away and finish setting up the authenticator app.

If the sign-in page ever asks you to set up an authenticator when you did not choose Start, tell the coach. The coach's fix is a reset.
